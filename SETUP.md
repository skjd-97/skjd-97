# GitHub Hacker Theme Profile — Setup

## Files
- `README.md` — profile page content
- `assets/hacker-terminal.svg` — green terminal banner

## Upload on Android
1. Open GitHub and create a **public repository** whose name is exactly your GitHub username.
   Example: if your username is `sajid123`, the repository name must be `sajid123`.
2. Keep **Add a README file** enabled, or create the repository empty.
3. Open the repository → **Add file** → **Upload files**.
4. Upload `README.md`.
5. Create the `assets` folder and upload `hacker-terminal.svg` into it. If GitHub mobile doesn't let you select folders, upload files individually; create `assets/hacker-terminal.svg` using **Add file → Create new file** and type that path.
6. In `README.md`, replace every `YOUR-USERNAME` with your exact GitHub username.
7. Commit changes. The README should appear on your GitHub profile.

This is a visual hacker/terminal theme for a profile; it does not perform hacking or access other systems.
